# PSI-Cardinality 档（openmined-psi 计数档）的依赖 —— **哈希固定**版
#
# 用法（安装即校验：拿不到这个产物、或哈希对不上，pip 直接失败，不会静默降级）：
#   python -m pip install -r requirements-psi-ca.txt
#
# 为什么钉哈希（而不只钉版本号）：
#   openmined-psi 是外部二进制轮子（内含 ECDH/BloomFilter 原生实现），本项目
#   依赖它给出「交集基数」这种对外结论。只钉版本号挡不住「版本号没变、产物
#   被换掉」的静默漂移。哈希值取自 PyPI 官方 JSON API
#   （https://pypi.org/pypi/openmined-psi/2.0.6/json 的 digests.sha256；
#   protobuf 同法取自 https://pypi.org/pypi/protobuf/6.30.2/json），
#   与 docs/PSI_CA_CAPABILITY.md §8 的表格逐字一致。
#
# 平台范围：本档只在 Linux / WSL2 跑（PyPI 上 openmined-psi **没有 Windows
#   轮子**）。下表覆盖 Python 3.10 / 3.11 的 manylinux x86_64 轮子：
#   - manylinux_2_39 = Ubuntu 24.04 一类（glibc >= 2.39；本仓库 WSL2 实测环境）
#   - manylinux_2_35 = Ubuntu 22.04 一类（glibc >= 2.35）
#   换平台/换小版本（cp312+）前，先取该轮子的 sha256 再加一行——不要放宽成
#   「不校验」。若所在平台不在表内，pip 会报「hashes 不匹配」而不是装个别的。
